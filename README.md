📋Sistema CRUD em Python
Projeto simples de CRUD (Create, Read, Update, Delete) desenvolvido em Python utilizando a biblioteca Rich para deixar a interface do terminal mais bonita e organizada.

🚀Funcionalidades
✅ Criar cadastro
✅ Listar cadastros
✅ Atualizar cadastro
✅ Excluir cadastro
✅ Validação de entradas
✅ Interface estilizada no terminal

🛠Tecnologias Utilizadas
Python 3
Rich

▶️Como Executar
Execute o arquivo principal:
python main.py

📸Interface

O sistema possui um menu interativo no terminal com as opções:
1. Criar novo cadastro
2. Lista cadastro
3. Atualizar cadastro
4. Excluir cadastro
5. Sair
6.
